# SimpleWEBServer

## EX01 Developing a Simple Webserver

**Date:** 29-09-2026

## AIM:
To develop a simple webserver to serve HTML pages displaying the TCP/IP Protocol Suite, student name, and register number.

## DESIGN STEPS:

### Step 1:
Create the `index.html` file containing student details (Name & Register Number) and the TCP/IP Protocol Suite hierarchy.

### Step 2:
Start the Python HTTP server locally using `python -m http.server 8000`.

### Step 3:
Open `http://localhost:8000` in the browser to verify page rendering.

### Step 4:
Take a screenshot (`output.png`) of the web page and save it in the project directory.

### Step 5:
Commit and push all project files (`index.html`, `output.png`, and `README.md`) to the GitHub repository.
